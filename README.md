# trading-view

Локальный мульти-графиковый дашборд, бесплатный аналог платных функций TradingView:
до 8 графиков на экране, неограниченное число индикаторов, Volume Profile и Fair Value Gap.

- Графики: [Lightweight Charts](https://github.com/tradingview/lightweight-charts) v5 (лежит в `static/vendor`, интернет для неё не нужен)
- Крипта: Hyperliquid — история через REST, live-свечи через публичный websocket (без ключей)
- Акции США, Азии (Токио, Гонконг, Китай, Корея) и Европы (Xetra, LSE, Париж, Амстердам): yfinance через маленький Flask-бэкенд, обновление каждые 15 с
- Фронтенд: чистые HTML/CSS/JS, без фреймворков и сборки

## Запуск

Нужен Python 3.10+. Одна команда (macOS/Linux):

```bash
./run.sh
```

Скрипт при первом запуске создаст `.venv`, поставит зависимости и откроет http://127.0.0.1:5050.
Другой порт: `PORT=8000 ./run.sh`. Порт 5000 не используется, потому что на macOS его занимает AirPlay Receiver.

Вручную (и на Windows):

```bash
python -m venv .venv
source .venv/bin/activate          # Windows: .venv\Scripts\activate
pip install -r requirements.txt
python app.py
```

## Что умеет

Интерфейс в стиле TradingView: сверху панель (символ, таймфреймы, тип графика, индикаторы, число графиков, синхронизация, раскладки, PNG), слева инструменты рисования, справа вотчлист.

- **Число графиков** 1, 2, 4, 6, 8 (1 = весь экран, 2 = рядом, 4 = 2×2, 6 = 3×2, 8 = 4×2). Клик по графику делает его активным (синяя рамка): верхняя панель управляет им. Двойной клик по шапке или Alt+M разворачивает график на весь экран, Esc возвращает.
- **Рынки**: Crypto (Hyperliquid, live по websocket), US stocks, Asia и Europe (yfinance, обновление раз в 15 с), Russia MOEX (бесплатный MOEX ISS). Символ: просто начните печатать, или впишите любой тикер в формате Yahoo (`7203.T` Токио, `0700.HK` Гонконг, `600519.SS` Шанхай, `005930.KS` Корея, `SAP.DE`, `AZN.L`, `MC.PA`, `ASML.AS`, индексы `^N225`, `^HSI`, `^GDAXI`, `^FTSE`; крипта `kPEPE`; MOEX `IMOEX`). Чтобы вернуть Индию, добавьте в `SOURCES` ещё один источник на `yahoo` с тикерами `RELIANCE.NS`, `^NSEI`.
- **Таймфреймы**: 1m, 5m, 15m, 30m, 1h, D, W, M. История подгружается при прокрутке влево.
- **Типы графика**: свечи, Heikin Ashi, бары, линия, область. Лог-шкала (Alt+L), переворот шкалы (Alt+I).
- **Индикаторы, без лимита**, можно добавлять один и тот же несколько раз с разными периодами и цветами (двойной клик по строке в легенде или шестерёнка):
  - Скользящие: SMA, EMA, WMA
  - На цене: Volume, Bollinger, Keltner, Donchian, VWAP, Supertrend, Parabolic SAR, Ichimoku
  - Осцилляторы (каждый в своей панели): RSI, MACD, Stochastic, Williams %R, CCI, MFI, ADX/DMI, ATR, OBV
  - PRO: **Volume Profile** (POC/VAH/VAL) и **Fair Value Gap** (зелёные бычьи, красные медвежьи)
  - Новый индикатор: строка в `static/indtable.js` + функция расчёта в `static/indicators.js`.
- **Рисование**: инструменты сгруппированы как в TradingView: кнопка группы запускает последний выбранный инструмент, стрелка `›` рядом открывает меню группы. Линии (тренд, линия-инфо, угол, луч, расширенная, горизонталь, вертикаль, перекрестие), каналы (параллельный, плоский верх/низ), вилы; Фибоначчи (коррекция, расширение по тренду, временные зоны, веер) и Ганн (веер, коробка); паттерны (XABCD, Cypher, ABCD, «голова и плечи», три движения), волны Эллиотта (12345, ABC), циклы; прогноз (long/short с R/R, прогноз), anchored VWAP, диапазоны (цена, время, цена+время); кисть, маркер-выделитель, стрелки; фигуры (прямоугольник, круг, эллипс, треугольник); текст, заметка, метка цены, флаг. Не сделано: регрессионный канал, расходящийся канал, дуги/спираль, профиль объёма по диапазону, таблицы, изображения и идеи. Магнит к OHLC, замок (рисунки нельзя выделить), скрыть все, undo/redo. Нарисованное можно выделить кликом, перетащить целиком или за точки, поменять цвет, толщину, стиль, удалить (Del) по одному. Рисунки привязаны к символу и видны на любом таймфрейме.
- **Алерты**: у горизонтальной линии кнопка 🔔; когда цена пересечёт линию, будет звук, всплывашка и уведомление (страница должна быть открыта).
- **Вотчлист** справа: котировки и изменение за день, live для крипты, клик переключает активный график, «+» добавляет символ.
- **Синхронизация**: общий курсор по времени и общий символ между графиками.
- **Демо-торговля**: кнопка **Trading** справа в шапке.
  - **Paper Trading**: виртуальный счёт в USD или RUB с Market и Limit ордерами, лонгом и шортом, SL/TP, комиссией и проскальзыванием, плюс история ордеров и баланса.
  - **Replay Trading**: та же торговля на истории с выбранной даты. График идёт как живой, будущие свечи скрыты, пробел ставит на паузу и снимает с неё, скорость 1×, 2×, 5× или 10×, можно шагнуть на бар или перейти к дате.
  - Сделки, позиции, SL/TP и лимитки видны на графике. **Report** показывает итоги: доходность, win rate, profit factor, просадку, комиссии, время в рынке и сравнение с buy & hold. **Reset** с подтверждением возвращает счёт к начальному капиталу.
  - Реальных ордеров нет. Подробности в [docs/trading.md](docs/trading.md).
- **Раскладки**: сохранить набор графиков под именем («Крипта скальп») и вернуть одним кликом. **PNG**: кнопка с камерой или Alt+S.
- Тикер-бар над каждым графиком вспыхивает зелёным/красным при изменении цены. Бейджи: HL live, US/Tokyo/HK/EU/RU открыта/закрыта (точка, название при наведении; по расписанию, без учёта праздников и обеденных перерывов).
- **Маленькие окна**: ниже 1250 px бейджи сжимаются до точек, ниже 1100 px таймфреймы уходят в выпадающий список, а вотчлист открывается поверх графиков, ниже 900 px графики идут в одну колонку.

### Горячие клавиши

Список открывается по `?`.

| Клавиши | Действие |
|---|---|
| начать печатать | поиск символа |
| `/` | индикаторы |
| `Alt+T` / `Alt+H` / `Alt+J` / `Alt+V` / `Alt+C` / `Alt+F` / `Alt+Shift+R` | тренд / горизонталь / горизонтальный луч / вертикаль / перекрестие / Фибоначчи / прямоугольник |
| `Del` | удалить выделенный рисунок |
| `Ctrl/Cmd+Z`, `Ctrl/Cmd+Shift+Z` | отменить / вернуть изменение рисунков |
| `Esc` | отмена рисования, снять выделение, свернуть полноэкранный график |
| `Alt+I` / `Alt+L` / `Alt+R` | перевернуть шкалу / лог-шкала / сбросить вид |
| `Alt+M` / `Alt+W` / `Alt+S` | развернуть график / вотчлист / PNG |
| `Пробел` | replay: пауза / воспроизведение |

### Где хранятся данные

Настройки, рисунки и раскладки лежат в папке `state/` (JSON-файлы, в git не попадают), поэтому не зависят от браузера и адреса (`localhost` или `127.0.0.1`).

## Как подключить другого брокера

Весь доступ к данным — в `data_source.py`. Добавьте одну функцию `fetch(symbol, tf, before=None)`, которая
возвращает список свечей `{"time", "open", "high", "low", "close", "volume"}`, и зарегистрируйте её в `SOURCES` —
новый рынок появится в выпадающем списке каждого графика. Пример для Binance есть в начале файла.
Alpaca, Zerodha, Polygon и т.п. подключаются так же (их API-ключи — уже ваша забота).

## Отметки сделок paper-бота

На графике BTC (Crypto) рисуются стрелки бота: синяя вверх = вход в лонг (`Bot BUY <кол-во>`), красная/зелёная вниз = выход
(`SL` или `TP` и результат в USDT). Шорт зеркально: синяя вниз над свечой = вход (`Bot SHORT <кол-во>`), вверх под свечой = выход. Сделки берёт сервер из `analytics-api` (`GET /api/v1/trader/trades` проекта
Investment-Analytics-Platform) и отдаёт браузеру как `/api/bot/trades`; токен сервиса в браузер не попадает.
Нужны переменные `ANALYTICS_URL` и `ANALYTICS_TOKEN`; без них отметок нет, остальное работает как раньше.
Обновляются раз в минуту.

Кнопка **Bot** в шапке открывает итоги бота: число закрытых сделок, win rate, суммарный P&L в USDT, profit factor, максимальная просадка,
средний R, кривая накопленного P&L и таблица сделок со входом, стопом, целью, выходом и результатом. Клик по сделке ставит активный график на BTC
и показывает эту сделку. Считается в браузере из тех же `/api/bot/trades` (`static/botstats.js`, тест: `node tests/botstats.test.js`).

## Деплой на Railway (отдельный сервис)

1. Новый сервис из этого репозитория (запуск берётся из `Procfile`: gunicorn).
2. Вкладка **Variables**: `AUTH_PASSWORD` (логин `admin`, можно поменять через `AUTH_USER`), `HOST=0.0.0.0`,
   `ANALYTICS_URL=http://analytics-api.railway.internal:<порт analytics-api>`, `ANALYTICS_TOKEN` (ссылка на `SERVICE_TOKEN`
   сервиса `analytics-api`), `STATE_DIR=/data`.
3. Volume с точкой монтирования `/data`, иначе рисунки и раскладки пропадают при каждом деплое.
4. Сгенерируйте публичный домен. Без `AUTH_PASSWORD` приложение на Railway не запустится: иначе любой мог бы писать в
   его состояние и читать сделки бота.

## Ограничения

- Yahoo отдаёт 1m-данные только за последние ~7 дней, 5m–30m за 60 дней; котировки бывают с задержкой ~15 мин для некоторых бирж. Подгрузка истории влево упирается в эти же окна.
- MOEX: 5m и 15m строятся из минутных свечей, поэтому история на них короткая (несколько дней).
- Live для акций — опрос раз в 15 с, а не стрим (yfinance не даёт стрима).
- Время на оси — локальное время браузера.
